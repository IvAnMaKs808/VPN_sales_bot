# VPN-бот (Telegram + 3x-ui + Happ)

Telegram-бот, который **автоматически** продаёт доступ к VPN: принимает оплату
(ЮKassa / СБП / крипта), сам создаёт клиента в панели **3x-ui** и отдаёт
пользователю ссылку-подписку для приложения **Happ**. Ты только держишь VPS и
панель — всё остальное бот делает сам.

## Что уже умеет

- 🛒 Продажа тарифов (1 / 3 / 6 / 12 мес), кнопка **«Ввести промокод»** под тарифами
- 💳 Оплата: **ЮKassa** (карта + СБП) и **криптовалюта** (CryptoBot)
- 🎁 Пробный период (по умолчанию 3 дня, настраивается)
- 👥 Реферальная система: **30% пожизненно** с оплат приглашённого на баланс + **10 дней** за каждого приглашённого (при его первой оплате)
- 🎟 Промокоды: скидка % / фикс / бонусные дни, с лимитом активаций
- 🔑 Автосоздание и продление клиента в 3x-ui, стабильная ссылка для Happ
- ⏳ Напоминания об окончании подписки, авто-проверка оплат в фоне
- 🛠 Админ-панель в боте: статистика/выручка, выдача дней, бан, рассылка, промокоды, поиск юзера
- 🇷🇺 Полностью на русском

## Шаг 1. Что нужно подготовить (значения для `.env`)

| Значение | Где взять |
|---|---|
| `BOT_TOKEN` | @BotFather → новый бот |
| `ADMIN_IDS` | твой Telegram ID (@userinfobot). Несколько — через запятую |
| `SUPPORT_USERNAME` | юзернейм для кнопки «Поддержка» (без @) |
| `XUI_BASE_URL` | адрес панели 3x-ui вместе с web base path |
| `XUI_USERNAME` / `XUI_PASSWORD` | логин/пароль панели |
| `XUI_INBOUND_ID` | ID инбаунда VLESS Reality (см. шаг 2) |
| `XUI_SUB_BASE_URL` | базовый URL подписки из настроек панели (см. шаг 2) |
| `YOOKASSA_SHOP_ID` / `YOOKASSA_SECRET_KEY` | ЮKassa → Настройки → API-ключи |
| `CRYPTOBOT_TOKEN` | @CryptoBot → Crypto Pay → Create App → API Token |

Любой платёжный провайдер можно оставить пустым — он просто не покажется в боте.

## Шаг 2. Настройка 3x-ui (на VPS)

1. Установи 3x-ui (проект MHSanaei/3x-ui) и открой панель.
2. Создай **инбаунд**: протокол **VLESS**, security **Reality**, flow `xtls-rprx-vision`.
   Запиши его **ID** (виден в списке инбаундов) → это `XUI_INBOUND_ID`.
3. Включи **Subscription** (Настройки панели → Подписка): задай порт и путь.
   Итоговый базовый адрес вида `https://твой-домен:2096/sub` → это `XUI_SUB_BASE_URL`
   (без слэша в конце). Именно `XUI_SUB_BASE_URL/{subId}` бот отдаёт в Happ.
4. `XUI_BASE_URL` — адрес самой панели вместе с web base path, например
   `https://твой-домен:2053/mypanelpath` (без слэша в конце).

> Совет: используй домен + валидный сертификат. Если сертификат самоподписанный,
> бот всё равно подключится (проверка TLS отключена для панели), но домен надёжнее.

## Шаг 3. Установка и запуск бота

Бот можно запускать на том же VPS, где панель, или на отдельном.

```bash
# 1. Скопировать файлы бота на сервер, затем:
cd vpn-bot
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# 2. Создать конфиг и заполнить его
cp .env.example .env
nano .env          # вписать токены и адреса из шагов 1–2

# 3. Тестовый запуск
python bot.py
```

Если всё верно — в логе появится `Бот @имя запущен`. Открой бота в Telegram, нажми `/start`.

### Автозапуск через systemd (чтобы работал 24/7)

Создай файл `/etc/systemd/system/vpnbot.service`:

```ini
[Unit]
Description=VPN Telegram Bot
After=network.target

[Service]
Type=simple
WorkingDirectory=/root/vpn-bot
ExecStart=/root/vpn-bot/venv/bin/python /root/vpn-bot/bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
systemctl daemon-reload
systemctl enable --now vpnbot
systemctl status vpnbot      # проверить
journalctl -u vpnbot -f      # смотреть логи
```

## Шаг 4. Как менять цены и тарифы

Цены — в файле **`config.py`**, список `PLANS` (сейчас стоят цены-заглушки):

```python
PLANS = [
    Plan(code="m1",  title="1 месяц",   days=30,  price=149),
    Plan(code="m3",  title="3 месяца",  days=90,  price=399),
    Plan(code="m6",  title="6 месяцев", days=180, price=699),
    Plan(code="m12", title="1 год",     days=365, price=1199),
]
```

Меняй `price` (в рублях), `days`, `title`. Можно добавлять/удалять тарифы.
После правок — перезапусти бота (`systemctl restart vpnbot`).

Прочие параметры (триал, реферальный %, бонусные дни, лимит трафика) — в `.env`.

## Шаг 5. Админ-панель

Отправь боту команду **`/admin`** (работает только для ID из `ADMIN_IDS`):

- **📊 Статистика** — пользователи, активные подписки, выручка
- **🎁 Выдать дни** — `user_id количество_дней`
- **🚫 Бан / разбан** — по `user_id`
- **📢 Рассылка** — сообщение всем пользователям
- **🎟 Создать промокод** — `КОД процент фикс дни лимит`
  (напр. `SALE20 20 0 0 100` — скидка 20%, 100 активаций; `FREE7 0 0 7 50` — 7 дней бесплатно)
- **🔍 Найти пользователя** — карточка по `user_id`

## Структура проекта

```
bot.py            — точка входа, middleware, запуск
config.py         — настройки + ТАРИФЫ И ЦЕНЫ
.env              — секреты и параметры (не коммить!)
database.py       — SQLite (пользователи, подписки, платежи, промокоды, рефералы)
xui.py            — клиент 3x-ui API
subscription.py   — выдача/продление подписки (3x-ui + БД)
payments.py       — ЮKassa + CryptoBot
handlers_user.py  — меню, покупка, оплата, рефералка, промокоды, триал
handlers_admin.py — админ-панель
keyboards.py      — кнопки
texts.py          — все тексты (русский)
scheduler.py      — авто-проверка оплат + напоминания об окончании
```

## Как оплата превращается в доступ (кратко)

1. Пользователь выбирает тариф → способ оплаты.
2. Бот создаёт счёт в ЮKassa/CryptoBot и даёт ссылку на оплату.
3. Пользователь платит. Бот подтверждает оплату (кнопка «Я оплатил» или авто-поллинг в фоне).
4. Бот вызывает 3x-ui, создаёт/продлевает клиента, начисляет рефереру 30% + бонусные дни.
5. Пользователь получает ссылку-подписку → вставляет в **Happ** → подключается.

## Важные заметки

- **Один сервер сейчас.** Мультисервер/выбор локаций можно добавить позже (несколько инбаундов/нод).
- **Без публичного вебхука.** Статус оплаты бот проверяет опросом — это упрощает деплой (не нужен домен под вебхук именно для бота). При желании можно перевести на вебхуки.
- **База — SQLite** (`vpnbot.db`). Делай бэкап этого файла. Для больших нагрузок можно перейти на PostgreSQL.
- `.env` и `vpnbot.db` содержат секреты и данные пользователей — не выкладывай их публично.
